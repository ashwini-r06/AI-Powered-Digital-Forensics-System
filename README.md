# AI-Powered-Digital-Forensics-System

AI-assisted digital forensics and incident response platform for evidence analysis, threat detection, and incident management.

## Features

- Digital evidence ingestion and integrity verification
- Security log normalization and analysis
- Rule-based threat detection
- Anomaly detection
- Event correlation and incident timeline generation
- Incident response management
- PDF report generation

## Technologies Used

- Python
- Streamlit
- SQLite
- Machine Learning

## Installation and Usage

1. Clone or download this repository.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Run the application:

   ```bash
   streamlit run app.py
   ```
